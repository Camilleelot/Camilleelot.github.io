Color System Reference

Edward Tufte-inspired minimal palette for Camille's Lot

Design Philosophy

This color system follows Edward Tufte's principles of information design:

  • Minimal - Only 4 accent colors (Primary, Secondary, Accent, Success)
  • Muted - Desaturated earth tones, no garish colors
  • Purposeful - Each color has semantic meaning
  • Accessible - WCAG AA compliant contrast ratios in both light and dark modes

Usage Guidelines

When to use each color:

  • Primary (Slate Blue) - Main research content, publication cards, primary CTAs, section headings
  • Secondary (Burnt Sienna) - Tools, interactive elements, data visualization accents, hover states
  • Accent (Burgundy) - Key findings, warnings, critical insights, emphasis within text
  • Success (Sage Green) - Positive outcomes, confirmations, success messages

Implementation

Add this to the <head> of all HTML pages:

<link rel="stylesheet" href="colors.css">

Then use CSS custom properties in your styles:

.my-research-card {
  background: var(--color-bg-card);
  border-left: 4px solid var(--color-primary);
}

.my-heading {
  color: var(--color-primary);
}

.my-button {
  background: var(--color-primary);
  color: var(--color-bg);
}

.my-button:hover {
  background: var(--color-secondary);
}

Pre-built Classes

Or use the utility classes provided in colors.css:

<div class="card-research">...</div>
<div class="card-tool">...</div>
<button class="cta-button">Read Paper</button>
<span class="badge-research">POLICY ANALYSIS</span>

Migration Path

To update existing pages:

  1. Add <link rel="stylesheet" href="colors.css"> to the page
  2. Replace hardcoded colors with CSS variables:
    • #2c5282 (fleet blue) → var(--color-primary)
    • #cc0000 (Calgary red) → var(--color-accent)
    • #2d5016 (turnover green) → var(--color-success)
    • #ff6b35 (scrollytelling orange) → var(--color-secondary)
  3. Use semantic classes where possible (.card-research, .badge-tool, etc.)
  4. Test in both light and dark modes
