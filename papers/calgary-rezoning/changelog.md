# Changelog: The Rezoning Paradox

All notable changes to this research paper will be documented in this file, following the academic preprint model (similar to arXiv versioning).

## Version 1.0 (2025-11-15)

**Initial Publication**

### Summary
First public release of the Calgary rezoning analysis. This version presents interrupted time series analysis of housing construction starts following Calgary's August 2024 blanket rezoning policy.

### Key Findings
- Monthly housing starts fell 16% below pre-existing growth trend post-rezoning
- Immediate crash of 568 units following policy implementation
- Construction shifted toward multi-family (15.9% increase) but insufficient to offset single-family decline (2.3% increase)
- Cohen's d = -1.18 indicating large negative effect

### Methodology
- 17-month observation window (Nov 2023 - Mar 2025)
- 9 pre-intervention, 8 post-intervention data points
- Interrupted time series regression with counterfactual projection
- CMHC Housing Starts Survey as primary data source

### Data Sources
- Canada Mortgage and Housing Corporation (CMHC) monthly housing starts
- City of Calgary Land Use Bylaw documentation
- Calgary Housing Strategy 2024-2030

### Contents
- Interactive time series visualizations
- Compositional analysis by housing type
- Density ratio trends
- Statistical robustness measures

### Known Limitations
- Short post-intervention window (8 months)
- Price effects not yet observable
- No cross-city comparison (Edmonton implemented similar policy simultaneously)
- Community sentiment surveys unavailable for before/after analysis
