About This Repository

Curator: Camille Moreau

Type: Data Repository

Geographic Coverage: Calgary Census Metropolitan Area

Description

Curated dataset of housing construction and rental market data for the Calgary Census Metropolitan Area, sourced from Canada Mortgage and Housing Corporation (CMHC). This repository supports policy analysis of Calgary's housing market, including the 2024 blanket rezoning intervention. Data includes monthly housing starts by dwelling type, raw CMHC survey data, and rental market indicators.

Available Versions

Dataset versions track updates to data coverage, additions of new indicators, and improvements to data quality.
