# Changelog: CMHC Housing Data Repository

All notable changes to this dataset will be documented in this file.

## Version 1.0 (2025-11-15)

**Initial Publication**

### Summary
First public release of the curated CMHC housing data repository for Calgary CMA. This version provides the foundational dataset used in "The Rezoning Paradox" policy analysis.

### Datasets Included
- **Housing Starts:** Monthly construction starts by dwelling type (Nov 2023 - Mar 2025)
- **Raw CMHC Data:** Unprocessed survey data as downloaded
- **Rental Market Data:** Vacancy rates and rent indicators for Calgary CMA

### Data Coverage
- **Temporal Range:** November 2023 - March 2025 (17 months)
- **Geographic Area:** Calgary Census Metropolitan Area
- **Dwelling Types:** Single-detached, semi-detached, row houses, apartments

### Data Sources
- CMHC Housing Starts and Construction Survey
- CMHC Rental Market Survey

### Format & Structure
- Primary format: CSV for processed data
- Raw data preserved in original formats
- Organized by data type in subdirectories

### Known Limitations
- Relatively short time series (17 months)
- No community-level disaggregation (CMA-level only)
- Price data not yet included
- No historical baseline beyond Nov 2023
